Подключение Telegram News Bot

Нужен только токен, который выдал BotFather. Chat ID, API новостей и другие ключи вводить не нужно.

  • 1Вставь токен и нажми «Подключить бота».
  • 2Открой своего бота в Telegram и нажми /start.
  • 3Дайджест будет приходить каждый день в 09:00 по Europe/Berlin. Время меняется командой /time HH:MM.
Токен отправляется напрямую в backend бота по HTTPS и не записывается в эту HTML-страницу.
